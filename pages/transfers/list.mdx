Lista as transferências da conta, nas duas direções (entrada e saída), da mais recente para a mais antiga. Use `direction` para filtrar.

Permissão: `transfer.read`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.dev/v1/transfers \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -d "direction=out" \
  -d "page=1" \
  -d "limit=15"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const { data, count } = await upag.transfers.list({
  direction: 'out',
  page: 1,
  limit: 15,
});
```
</CodeGroup>

## Parâmetros

<ParamField query="direction" type="string">
  `in` (Pix recebido) ou `out` (Pix enviado). Sem o filtro, traz as duas. Valor desconhecido retorna `422`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Página, a partir de 1.
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Itens por página, mínimo 1.
</ParamField>

## Resposta

`200 OK`. `count` é o total de transferências da conta.
