## Dúvidas comuns

<Accordion title="Onde criar a sessão de checkout?">
  No client: `upag-js` + `pk_...`. No servidor: pacote `upag` + `sk_...`. Os dois falam com o mesmo recurso REST de checkout sessions.
</Accordion>

<Accordion title="Preciso de SDK?">
  Não. Requests `Authorization: Bearer` + JSON contra a Referência são suficientes.
</Accordion>

<Accordion title="Onde guardar cada chave?">
  Secret (`sk_...`) apenas no backend. Public (`pk_...`) pode ir no bundle do front. Não versione secret em git.
</Accordion>
