openapi: 'GET /v1/webhooks'
---

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.io/v1/webhooks \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -d "limit=20" \
  -d "offset=0"
```
</CodeGroup>
