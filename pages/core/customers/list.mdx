## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.io/v1/customers \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -d "limit=20" \
  -d "offset=0"
```
</CodeGroup>
