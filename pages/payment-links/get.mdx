---
title: 'Obter link de pagamento'
description: 'Consulta um link de pagamento pelo ID'
sidebarTitle: 'Obter'
api: 'GET https://api.upag.io/v1/payment-links/{paymentLinkId}'
---

Permissão: `payment_link.read` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/payment-links/d4e5f6a7-b8c9-4d0e-9f1a-2b3c4d5e6f70 \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const link = await upag.paymentLinks.retrieve('d4e5f6a7-b8c9-4d0e-9f1a-2b3c4d5e6f70');
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="paymentLinkId" type="string (uuid)" required>
  ID do link de pagamento.
</ParamField>
