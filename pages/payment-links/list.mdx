title: 'Listar links de pagamento'
description: 'Lista os links da conta, do mais novo para o mais antigo'
sidebarTitle: 'Listar'
api: 'GET https://api.upag.io/v1/payment-links'
---

Permissão: `payment_link.read` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.dev/v1/payment-links \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -d "active=true" \
  -d "type=fixed_amount" \
  -d "page=1" \
  -d "limit=15"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const { data, count } = await upag.paymentLinks.list({
  active: true,
  type: 'fixed_amount', // ou 'product'
  page: 1,
  limit: 15,
});
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField query="page" type="integer" default="1">
  Página (mínimo 1).
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Itens por página (mínimo 1).
</ParamField>

<ParamField query="name" type="string">
  Filtra por nome.
</ParamField>

<ParamField query="active" type="boolean">
  `true` ou `false`.
</ParamField>

<ParamField query="product" type="string (uuid)">
  Filtra links que vendem esse produto.
</ParamField>

<ParamField query="type" type="string">
  `product` ou `fixed_amount`.
</ParamField>
