Cria um link do tipo `product` (padrão), que vende preços do catálogo, ou `fixed_amount`, que cobra um valor próprio sem itens. Veja os [tipos de link](./reference).

Permissão: `payment_link.write` (chave secreta; chave publicável não é aceita).

## Endpoint

<CodeGroup>
```bash cURL
curl -X POST https://api.upag.io/v1/payment-links \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Plano Pro com trial",
    "successUrl": "https://example.com/obrigado",
    "items": [
      { "price": "5f2d7a90-3b1c-4e8a-8f6d-1c9e4b7a2d33", "quantity": 1 }
    ],
    "subscriptionData": {
      "trial": { "interval": "day", "intervalCount": 14 },
      "trialSettings": { "endBehavior": { "missingPaymentMethod": "cancel" } },
      "maxCycles": 12
    },
    "paymentMethodCollection": "always"
  }'
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_live_your_api_key');

const link = await upag.paymentLinks.create({
  name: 'Plano Pro com trial',
  successUrl: 'https://example.com/obrigado',
  items: [{ price: '5f2d7a90-3b1c-4e8a-8f6d-1c9e4b7a2d33', quantity: 1 }],
  subscriptionData: {
    trial: { interval: 'day', intervalCount: 14 }, // day ≤ 730, week ≤ 104, month ≤ 24
    trialSettings: { endBehavior: { missingPaymentMethod: 'cancel' } }, // ou 'create_invoice' (padrão)
    maxCycles: 12, // null (padrão) renova até cancelar
  },
  paymentMethodCollection: 'always', // ou 'if_required'
});
```

```bash cURL (valor fixo)
curl -X POST https://api.upag.io/v1/payment-links \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "fixed_amount",
    "name": "Consultoria avulsa",
    "amount": 15000,
    "paymentMethods": ["pix", "card", "boleto"]
  }'
```

```javascript Node.js SDK (valor fixo)
import { Upag } from 'upag';

const upag = new Upag('sk_live_your_api_key');

const link = await upag.paymentLinks.create({
  type: 'fixed_amount',
  name: 'Consultoria avulsa',
  amount: 15000, // R$ 150,00
  paymentMethods: ['pix', 'card', 'boleto'],
});
```
</CodeGroup>

<Note>
  Os exemplos usam produção (`https://api.upag.io/v1`) com `sk_live_…`. Para testar, use o sandbox (`https://api.upag.dev/v1`) com `sk_test_…`.
</Note>

## Parâmetros

<ParamField body="type" type="string" default="product">
  `product` ou `fixed_amount`. Não muda depois da criação.
</ParamField>

<ParamField body="name" type="string" required>
  Nome do link (1 a 255 caracteres).
</ParamField>

<ParamField body="items" type="array">
  Obrigatório em links `product`. Mínimo 1 item: `{ "price": "uuid", "quantity": inteiro ≥ 1 }`. O mesmo `price` não pode repetir, e o preço não pode estar [arquivado](../prices/reference).
</ParamField>

<ParamField body="amount" type="integer">
  Obrigatório em links `fixed_amount`. Valor cobrado, em centavos, de `500` (R$ 5,00) a `2147483647`.
</ParamField>

<ParamField body="description" type="string | null">
  Descrição.
</ParamField>

<ParamField body="checkoutLayout" type="string (uuid) | null">
  ID de um [layout de checkout](../checkout-layouts/reference) da conta.
</ParamField>

<ParamField body="paymentMethods" type="string[]" default='["pix", "card"]'>
  `pix`, `card` e/ou `boleto` (mínimo 1).
</ParamField>

<ParamField body="billingAddressCollection" type="string" default="auto">
  `auto`, `required` ou `none`.
</ParamField>

<ParamField body="successUrl" type="string (url) | null">
  URL de redirecionamento após o pagamento.
</ParamField>

<ParamField body="cancelUrl" type="string (url) | null">
  URL de redirecionamento se o comprador desistir.
</ParamField>

<ParamField body="subscriptionData" type="object">
  Só em links `product`. Configura as assinaturas criadas pelos itens recorrentes. Todos os campos são opcionais.

  - `trial`: `{ "interval": "day" | "week" | "month", "intervalCount": inteiro ≥ 1 }` (limites: `day` ≤ 730, `week` ≤ 104, `month` ≤ 24) ou `null` para sem trial.
  - `trialSettings.endBehavior.missingPaymentMethod`: `create_invoice` (padrão) ou `cancel`.
  - `maxCycles`: inteiro ≥ 1 com o número de períodos cobrados antes de a assinatura terminar (status `ended`), sem contar o trial, ou `null` (padrão) para renovar até ser cancelada.
</ParamField>

<ParamField body="paymentMethodCollection" type="string" default="always">
  Só em links `product`. `always` ou `if_required`. Define se o comprador deve deixar um método de pagamento quando nada é cobrado hoje (trial).
</ParamField>

<ParamField body="bumps" type="array" default="[]">
  Só em links `product`. Ofertas adicionais: `{ "price": "uuid", "quantity": inteiro ≥ 1 (padrão 1), "amount": centavos ≥ 0 (padrão preço × quantidade), "title": string até 255, "description": string }`.
</ParamField>

Um link `fixed_amount` aceita apenas `type`, `name`, `description`, `checkoutLayout`, `paymentMethods`, `billingAddressCollection`, `successUrl`, `cancelUrl` e `amount`; qualquer outro campo (como `items`, `bumps` ou `subscriptionData`) é recusado com `422`.

O link nasce `active: true` e `couponEnabled: false`; ajuste em [Atualizar link](./update).

## Erros

- `404` — `PRICE_NOT_FOUND`, `PRODUCT_NOT_FOUND` ou `CHECKOUT_LAYOUT_NOT_FOUND`.
- `400` — `PRICE_ARCHIVED` (um item ou bump usa um preço arquivado) ou outras violações das [regras de consistência](./reference).
- `400` — `ACCOUNT_PAYMENT_METHOD_DISABLED`: num link `fixed_amount`, uma das `paymentMethods` está desativada na conta.
- `422` — `PAYMENT_METHOD_AMOUNT_TOO_LOW` ou `PAYMENT_METHOD_AMOUNT_TOO_HIGH`: num link `fixed_amount`, o `amount` fica fora dos limites de valor de uma das `paymentMethods`.
- `422` — validação do corpo (`VALIDATION_FAILED`), inclusive campos de link `product` enviados num link `fixed_amount`.
