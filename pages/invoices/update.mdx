Finaliza um rascunho com `{ "open": true }`, deixando a fatura pronta para [pagamento](./pay). Esta é a única alteração que o endpoint aceita; para mudar o conteúdo de um rascunho, use os endpoints de [itens](./create-item).

Permissão: `invoice.write`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -X PATCH https://api.upag.dev/v1/invoices/5b0e8d3a-9c71-4e26-a8f4-1d7c3b6e9a02 \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{ "open": true }'
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const invoice = await upag.invoices.update('5b0e8d3a-9c71-4e26-a8f4-1d7c3b6e9a02', {
  open: true,
});
```
</CodeGroup>

## Parâmetros

<ParamField path="invoiceId" type="string (uuid)" required>
  ID da fatura.
</ParamField>

<ParamField body="open" type="boolean">
  `true` abre o rascunho: recalcula `amountDue` e muda o status para `open`. Depois de aberta, os itens ficam travados.
</ParamField>

## Erros

| Status | Código | Quando |
| ------ | ------ | ------ |
| `404` | `INVOICE_NOT_FOUND` | A fatura não existe ou é de outra conta |
| `400` | `INVOICE_NO_ITEMS` | O rascunho não tem itens |
| `400` | `INVOICE_INVALID_TRANSITION` | A fatura não é um rascunho (já está aberta, paga etc.) |
