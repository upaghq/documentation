---
title: 'Atualizar Fatura'
description: 'Atualiza uma fatura existente'
openapi: 'PATCH /api/v1/invoices/{id}'
---

Envia uma atualização para a fatura identificada por `id`. Na implementação atual, o corpo da requisição **não é lido nem aplicado** — campos como método de pagamento, vencimento ou descrição **não são alterados** por este endpoint. A resposta devolve a fatura após a operação interna (equivalente a recarregar o registro).

Para alterar itens em rascunho, use os endpoints de [itens da fatura](./items).

<Info>
  Comportamento sujeito a evolução futura da API. Enquanto isso, não dependa de `PATCH /v1/invoices/:id` para mudar dados da fatura.
</Info>

## Endpoint

```bash cURL
curl -X PATCH https://api.upag.io/v1/invoices/inv_abc123xyz \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{}'
```

## Parâmetros

<ParamField path="id" type="string" required>
  ID único da fatura, começando com `inv_`.
</ParamField>
