---
title: 'Atualizar Fatura'
description: 'Atualiza os dados de uma fatura existente'
openapi: 'PATCH /api/v1/invoices/{id}'
---

Atualiza os dados de uma fatura. Somente faturas com status `draft` podem ser atualizadas.

## Endpoint

```bash cURL
curl -X PATCH https://api.upag.io/v1/invoices/inv_abc123xyz \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "paymentMethod": "pm_def456ghi",
    "dueDate": 1731795000000
  }'
```

## Parâmetros

<ParamField path="id" type="string" required>
  ID único da fatura, começando com `inv_`.
</ParamField>

<ParamField body="paymentMethod" type="string">
  ID do método de pagamento a ser utilizado.
</ParamField>

<ParamField body="dueDate" type="number">
  Timestamp Unix da nova data de vencimento.
</ParamField>

<ParamField body="description" type="string">
  Descrição interna da fatura.
</ParamField>
