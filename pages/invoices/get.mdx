Retorna uma fatura com seus itens, descontos e as tentativas de pagamento (`payments`).

Permissão: `invoice.read`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/invoices/5b0e8d3a-9c71-4e26-a8f4-1d7c3b6e9a02 \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const invoice = await upag.invoices.retrieve('5b0e8d3a-9c71-4e26-a8f4-1d7c3b6e9a02');
```
</CodeGroup>

## Parâmetros

<ParamField path="invoiceId" type="string (uuid)" required>
  ID da fatura.
</ParamField>
