---
title: 'Buscar Fatura por ID'
description: 'Retorna os detalhes de uma fatura específica'
openapi: 'GET /api/v1/invoices/{id}'
---

Retorna as informações completas de uma fatura específica pelo seu ID.

## Endpoint

```bash cURL
curl https://api.upag.io/v1/invoices/inv_abc123xyz \
  -H "Authorization: Bearer {token}"
```

## Parâmetros

<ParamField path="id" type="string" required>
  ID único da fatura, começando com `inv_`.
</ParamField>

```json Response
    {
      "id": "ii_abc123xyz",

}
```
