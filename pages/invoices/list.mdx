Lista as faturas da conta, da mais nova para a mais antiga, com filtros opcionais.

Permissão: `invoice.read`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.dev/v1/invoices \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -d "status=open" \
  -d "customer=8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83" \
  -d "page=1" \
  -d "limit=15"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const { data, count } = await upag.invoices.list({
  status: 'open',
  customer: '8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83',
  page: 1,
  limit: 15,
});
```
</CodeGroup>

## Query

<ParamField query="status" type="string">
  Filtra por status: `draft`, `open`, `paid`, `void` ou `uncollectible`.
</ParamField>

<ParamField query="customer" type="string (uuid)">
  Filtra pelas faturas de um cliente.
</ParamField>

<ParamField query="id" type="string (uuid)">
  Filtra por um ID específico.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Página, a partir de 1.
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Itens por página, mínimo 1.
</ParamField>

## Resposta

`200 OK`. `count` é o total de faturas que batem com o filtro, não o tamanho da página.
