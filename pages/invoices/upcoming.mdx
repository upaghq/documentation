---
title: 'Próxima Fatura'
description: 'Retorna a prévia da próxima fatura de uma assinatura'
openapi: 'GET /api/v1/invoices/upcoming'
---

Retorna a prévia da próxima fatura que será gerada para uma assinatura. Útil para mostrar ao cliente o valor da próxima cobrança.

## Endpoint

```bash cURL
curl -G https://api.upag.io/v1/invoices/upcoming \
  -H "Authorization: Bearer {token}" \
  -d subscription=sub_abc123xyz
```

## Parâmetros

<ParamField query="subscription" type="string" required>
  ID da assinatura para calcular a próxima fatura.
</ParamField>

<ParamField query="customer" type="string">
  ID do cliente para calcular a próxima fatura sem assinatura.
</ParamField>
