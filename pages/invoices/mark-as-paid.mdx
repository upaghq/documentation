Registra que a fatura foi paga por fora (transferência, dinheiro, outro meio). Nenhuma cobrança é criada e nenhum valor passa pela Upag: a fatura vira `paid`, `amountPaid` recebe `amountDue` e o webhook `invoice.paid` é disparado.

Permissão: `invoice.write`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -X POST https://api.upag.dev/v1/invoices/5b0e8d3a-9c71-4e26-a8f4-1d7c3b6e9a02/mark-as-paid \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const invoice = await upag.invoices.markAsPaid('5b0e8d3a-9c71-4e26-a8f4-1d7c3b6e9a02');
```
</CodeGroup>

## Parâmetros

<ParamField path="invoiceId" type="string (uuid)" required>
  ID da fatura. Sem corpo.
</ParamField>

## Resposta

## Erros

| Status | Código | Quando |
| ------ | ------ | ------ |
| `404` | `INVOICE_NOT_FOUND` | A fatura não existe ou é de outra conta |
| `400` | `INVOICE_NOT_PAYABLE` | A fatura não tem valor a pagar (`amountDue` é `0`) |
| `400` | `INVOICE_INVALID_TRANSITION` | A fatura não está `open`: rascunho, ou já `paid`, `void` ou `uncollectible` |
