A página inicial do portal: quem é o cliente e o que a sessão deixa ele gerenciar. Autenticação pelo token da sessão (veja [Portal do cliente](./portal-overview)).

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/portal/me \
  -H "Authorization: Bearer kV3n9xQ2mT8pZr4LwB6yHc1sDf7GjA0eNu5oXiRbYtE"
```

```javascript fetch
const response = await fetch('https://api.upag.dev/v1/portal/me', {
  headers: { Authorization: `Bearer ${token}` },
});
const me = await response.json();
```

```javascript Node.js SDK
import { Upag } from 'upag';

const { portal } = new Upag({ apiKey: token, baseURL: 'https://api.upag.dev/v1' });

const me = await portal.me();
```
</CodeGroup>

A assinatura vem no mesmo formato do [payload de assinatura](../webhooks/payload-subscription) (trecho omitido acima), com `eligiblePrices` em cada item.

<ParamField body="session" type="object">
  `id`, `flow`, `returnUrl`, `expiresAt` e as permissões da sessão (`paymentMethodUpdate`, `subscriptionUpdate`).
</ParamField>

<ParamField body="customer" type="object">
  O cliente com dados mascarados: documento e telefone parcialmente ocultos. `cards` traz os cartões utilizáveis (ativos e não vencidos), o padrão primeiro.
</ParamField>

<ParamField body="publishableKey" type="string">
  Chave publicável da conta para tokenizar um cartão novo em [Criar cartão](../cards/create). Se a conta não tem uma que possa ser exibida, a API cria.
</ParamField>

<ParamField body="subscriptions" type="array">
  As assinaturas do cliente que ainda podem mudar (todas exceto canceladas, void e encerradas). Com `flow`, só a assinatura do flow.
</ParamField>

<ParamField body="subscriptions[].items[].eligiblePrices" type="array">
  [Preços](../prices/reference) para os quais o item pode trocar: outros preços do **mesmo produto** permitidos na sessão, ativos, recorrentes, na moeda e no intervalo da assinatura. Vazio quando a sessão não permite troca de plano.
</ParamField>

<ParamField body="paymentMethods" type="array">
  Métodos ativos na conta: `pix`, `card` e/ou `boleto`.
</ParamField>

## Erros

| Status | Código | Causa |
| ------ | ------ | ----- |
| `401` | `AUTHENTICATION_REQUIRED` | Token ausente, desconhecido ou expirado |
| `403` | `feature_flag_disabled` | Portal de cobrança não habilitado para a conta |
| `404` | `CUSTOMER_NOT_FOUND` | O cliente da sessão foi excluído |
