Registra uma conta pelo código de barras ou linha digitável. O valor, o vencimento e o beneficiário vêm do banco, consultados na hora. Registrar não paga: use [Pagar conta](./pay) em seguida.

Permissão: `bill.write`. Apenas chave secreta (`sk_…`).

<Warning>
  O pagamento de contas precisa estar habilitado para a conta. Até lá, a rota responde `403 feature_flag_disabled`. Veja [Erros](../guides/errors#recurso-não-habilitado).
</Warning>

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -X POST https://api.upag.dev/v1/bills \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "barcode": "34191.09008 00122.130370 50059.980008 1 00000000025000",
    "description": "Aluguel novembro"
  }'
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const bill = await upag.bills.create({
  barcode: '34191.09008 00122.130370 50059.980008 1 00000000025000',
  description: 'Aluguel novembro',
});
```
</CodeGroup>

## Parâmetros

<ParamField body="barcode" type="string" required>
  Código de barras lido ou linha digitável, com ou sem pontos e espaços. 1 a 60 caracteres.
</ParamField>

<ParamField body="description" type="string">
  Até 140 caracteres. Uso interno.
</ParamField>

## Erros

| Status | Código | Causa |
| ------ | ------ | ----- |
| `400` | `ACCOUNT_NOT_ACTIVE` | A conta não está ativa |
| `403` | `feature_flag_disabled` | Pagamento de contas não habilitado para a conta |
| `409` | `BILL_ALREADY_EXISTS` | Já existe uma conta não cancelada com esse código de barras |
| `409` | `BILL_ALREADY_PAID` | O banco informa que a conta já foi paga |
| `422` | `BILL_BARCODE_INVALID` | Código de barras ou linha digitável inválido |
| `422` | `BILL_BARCODE_NOT_SUPPORTED` | Tipo de conta ainda não aceito (tributos) |
| `422` | `BILL_BARCODE_REJECTED` | O banco recusou o código. `message` traz o motivo |
| `422` | `VALIDATION_FAILED` | `barcode` ausente ou longo demais, ou `description` com mais de 140 caracteres |

Formato dos erros em [Erros](../guides/errors).
