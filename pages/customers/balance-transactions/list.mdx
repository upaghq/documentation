Lista as transações de saldo do cliente, da mais recente para a mais antiga.

Permissão: `customer.read`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.dev/v1/customers/8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83/balance-transactions \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -d "page=1" \
  -d "limit=15"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const { data, count } = await upag.customers.balanceTransactions.list(
  '8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83',
  { page: 1, limit: 15 },
);
```
</CodeGroup>

## Parâmetros

<ParamField path="customerId" type="string (uuid)" required>
  ID do cliente.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Página, a partir de 1.
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Itens por página, mínimo 1.
</ParamField>

## Erros

| Status | Código | Causa |
| ------ | ------ | ----- |
| `404` | `CUSTOMER_NOT_FOUND` | Cliente inexistente, excluído ou de outra conta |
| `422` | `VALIDATION_FAILED` | `customerId` não é UUID, ou paginação inválida |
