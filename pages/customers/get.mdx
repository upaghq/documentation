Permissão: `customer.read`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/customers/8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83 \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const customer = await upag.customers.retrieve('8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83');
```
</CodeGroup>

## Parâmetros

<ParamField path="customerId" type="string (uuid)" required>
  ID do cliente.
</ParamField>

## Erros

| Status | Mensagem | Causa |
| ------ | -------- | ----- |
| `404` | `Customer not found` | Cliente inexistente, excluído ou de outra conta |
| `422` | `VALIDATION_FAILED` | `customerId` não é UUID |
