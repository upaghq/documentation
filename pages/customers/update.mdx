Atualiza parcialmente o cliente: campos omitidos ficam como estão. O documento só pode ser informado **uma vez**, num cliente que ainda não tem um; depois de definido não pode ser alterado (crie outro cliente).

Permissão: `customer.write`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -X PATCH https://api.upag.dev/v1/customers/8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83 \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "maria.souza@example.com",
    "address": { "complement": "Apto 42" }
  }'
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const customer = await upag.customers.update('8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83', {
  email: 'maria.souza@example.com',
  address: { complement: 'Apto 42' },
});
```
</CodeGroup>

## Parâmetros

<ParamField path="customerId" type="string (uuid)" required>
  ID do cliente.
</ParamField>

<ParamField body="name" type="string">
  Nome (mínimo 1 caractere).
</ParamField>

<ParamField body="document" type="object">
  `{ type: "cpf" | "cnpj", number }`. Aceito só enquanto o cliente não tem documento; com um já definido, a requisição inteira é recusada com `409` e nada é alterado.
</ParamField>

<ParamField body="email" type="string | null">
  E-mail válido, ou `null` para limpar.
</ParamField>

<ParamField body="phone" type="object | null">
  Objeto completo (`countryCode`, `areaCode`, `number`), que substitui o anterior; ou `null` para limpar.
</ParamField>

<ParamField body="address" type="object | null">
  Campos do endereço a alterar (`street`, `number`, `complement`, `neighborhood`, `city`, `state`, `country`, `zip`), mesclados campo a campo; ou `null` para limpar todo o endereço.
</ParamField>

## Erros

| Status | Mensagem | Causa |
| ------ | -------- | ----- |
| `404` | `Customer not found` | Cliente inexistente, excluído ou de outra conta |
| `409` | `CUSTOMER_DOCUMENT_ALREADY_SET` | `document` enviado para um cliente que já tem documento |
| `422` | `VALIDATION_FAILED` | Corpo inválido |
