---
title: 'Excluir Sessão de Checkout'
description: 'Exclui uma sessão de checkout'
openapi: 'DELETE /api/v1/checkout-sessions/{id}'
---

Exclui uma sessão de checkout. Somente sessões com status `open` podem ser excluídas.

## Endpoint

```bash cURL
curl -X DELETE https://api.upag.io/v1/checkout-sessions/cs_abc123xyz \
  -H "Authorization: Bearer {token}"
```

## Parâmetros

<ParamField path="id" type="string" required>
  ID único da sessão de checkout, começando com `cs_`.
</ParamField>

## Resposta

```json Response
{
  "id": "cs_abc123xyz",
  "deleted": true
}
```
