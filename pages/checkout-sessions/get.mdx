---
title: 'Obter sessão de checkout'
description: 'Consulta uma sessão de checkout pelo servidor, com a chave secreta'
sidebarTitle: 'Obter'
api: 'GET https://api.upag.io/v1/checkout/sessions/{sessionId}'
---

Retorna uma sessão de checkout com seus itens, bumps e descontos. É a leitura do **seu servidor**, com a chave secreta. Para a leitura que a página de checkout faz com o `clientSecret`, veja [Obter sessão (pagador)](./retrieve).

Depois que a sessão é paga, `invoice` e `subscription` trazem os UUIDs da [fatura](../invoices/reference) e da [assinatura](../subscriptions/reference) criadas.

Permissão: `checkout_session.read`.

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/checkout/sessions/4f9d2b71-6c03-4e58-9a1d-8b3e7c0f5a26 \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const session = await upag.checkoutSessions.retrieve('4f9d2b71-6c03-4e58-9a1d-8b3e7c0f5a26');
```
</CodeGroup>

## Parâmetros

<ParamField path="sessionId" type="string (uuid)" required>
  ID da sessão.
</ParamField>
