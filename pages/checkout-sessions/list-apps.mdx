Lista os apps da conta (pixel da Meta, Trackup, Shopify e outros) que se aplicam aos produtos da sessão, só com a configuração pública que a página de checkout precisa. Credenciais nunca saem aqui.

Permissão: `checkout_session.read`. Aceita a chave secreta ou o `clientSecret` da sessão. A sessão precisa estar `open`.

<Note>
  Os exemplos usam o sandbox (`https://api.upag.dev/v1`). Em produção use `https://api.upag.io/v1` com `sk_live_…`; no navegador, o `upag-js` usa só a chave pública.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/checkout/sessions/4f9d2b71-6c03-4e58-9a1d-8b3e7c0f5a26/apps \
  -H "Authorization: Bearer Zk3v0pQ8xJ2mR7cYt1LwN5dHs9uAeB4gXo6iFqVjT0E"
```

```javascript upag-js
import { UpagJs } from 'upag-js';

const upag = new UpagJs('pk_test_your_public_key');

const { data } = await upag.checkout.listApps(id, clientSecret);
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const { data } = await upag.checkoutSessions.listApps('4f9d2b71-6c03-4e58-9a1d-8b3e7c0f5a26');
```
</CodeGroup>

## Parâmetros

<ParamField path="sessionId" type="string (uuid)" required>
  ID da sessão.
</ParamField>

## Resposta

`200 OK`

```json Response
{
  "data": [
    {
      "type": "integration",
      "provider": "meta",
      "config": { "pixelId": "1234567890" }
    },
    {
      "type": "integration",
      "provider": "trackup",
      "config": { "projectId": "prj_42", "hostname": "t.exemplo.com.br" }
    }
  ]
}
```

## Atributos

<ParamField body="type" type="string">
  `integration` ou `custom`.
</ParamField>

<ParamField body="provider" type="string">
  `meta`, `spedy`, `utmify`, `trackup` ou `shopify`.
</ParamField>

<ParamField body="config" type="object">
  Só os campos públicos de cada provedor: `meta` (`pixelId`), `trackup` (`projectId`, `hostname`) e `shopify` (`shop`, `scriptTagId`, `skipCart`). `spedy` e `utmify` não expõem nada (`{}`).
</ParamField>

A lista não é paginada.

## Erros

| Status | Código | Quando |
| ------ | ------ | ------ |
| `404` | `CHECKOUT_SESSION_NOT_FOUND` | Do servidor: a sessão não existe ou é de outra conta |
| `409` | `CHECKOUT_SESSION_NOT_OPEN` | A sessão já está `complete` ou `expired` |
