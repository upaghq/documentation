Lista os pagamentos de conta, do mais recente para o mais antigo.

Permissão: `bill.read`. Apenas chave secreta (`sk_…`).

<Warning>
  O pagamento de contas precisa estar habilitado para a conta. Até lá, a rota responde `403 feature_flag_disabled`. Veja [Erros](../guides/errors#recurso-não-habilitado).
</Warning>

<Note>
  Os exemplos usam produção (`https://api.upag.io/v1`) com `sk_live_…`. Para testar, use o sandbox (`https://api.upag.dev/v1`) com `sk_test_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.io/v1/bill-payments \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -d "page=1" \
  -d "limit=15" \
  -d "status=paid" \
  -d "startDate=2026-11-01T00:00:00.000Z" \
  -d "endDate=2026-11-30T23:59:59.999Z"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_live_your_api_key');

const { data, count } = await upag.billPayments.list({
  page: 1,
  limit: 15,
  status: 'paid',
  startDate: '2026-11-01T00:00:00.000Z',
  endDate: '2026-11-30T23:59:59.999Z',
});
```
</CodeGroup>

## Parâmetros

<ParamField query="page" type="integer" default="1">
  Página, a partir de 1.
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Itens por página, mínimo 1.
</ParamField>

<ParamField query="bill" type="string (uuid)">
  Só os pagamentos desta conta.
</ParamField>

<ParamField query="status" type="string">
  `pending`, `scheduled`, `awaiting_funds`, `paid`, `failed`, `canceled` ou `reversed`.
</ParamField>

<ParamField query="startDate" type="string">
  Só pagamentos criados a partir deste instante (data ou data e hora ISO 8601, inclusive).
</ParamField>

<ParamField query="endDate" type="string">
  Só pagamentos criados até este instante (inclusive). Uma data sem hora vale como meia-noite UTC do dia.
</ParamField>

## Erros

| Status | Código | Causa |
| ------ | ------ | ----- |
| `403` | `feature_flag_disabled` | Pagamento de contas não habilitado para a conta |
| `422` | `VALIDATION_FAILED` | `bill` não é UUID, `status` desconhecido ou data inválida |
