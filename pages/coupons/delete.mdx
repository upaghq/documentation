---
title: 'Excluir cupom'
description: 'Remove um cupom da conta'
sidebarTitle: 'Excluir'
api: 'DELETE https://api.upag.io/v1/coupons/{couponId}'
---

Exclusão lógica: o cupom deixa de aparecer na listagem e não pode mais ser aplicado.

Permissão: `coupon.write` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl -X DELETE https://api.upag.dev/v1/coupons/a3c4d5e6-7f80-4912-8abc-0d1e2f3a4b5c \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

await upag.coupons.delete('a3c4d5e6-7f80-4912-8abc-0d1e2f3a4b5c');
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="couponId" type="string (uuid)" required>
  ID do cupom.
</ParamField>

## Resposta

`204 No Content` — sem corpo em caso de sucesso.

`404` (`COUPON_NOT_FOUND`) se o cupom não existir.
