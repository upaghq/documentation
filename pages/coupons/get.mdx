---

Permissão: `coupon.read` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/coupons/a3c4d5e6-7f80-4912-8abc-0d1e2f3a4b5c \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const coupon = await upag.coupons.retrieve('a3c4d5e6-7f80-4912-8abc-0d1e2f3a4b5c');
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="couponId" type="string (uuid)" required>
  ID do cupom.
</ParamField>
