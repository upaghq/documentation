---

Permissão: `app.read` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/apps/b7c8d9e0-f1a2-4b3c-8d4e-5f6a7b8c9d01/logs/d9e0f1a2-b3c4-4d5e-8f6a-7b8c9d0e1f23 \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

// upag.apps.logs.retrieve(appId, logId)
const log = await upag.apps.logs.retrieve(
  'b7c8d9e0-f1a2-4b3c-8d4e-5f6a7b8c9d01',
  'd9e0f1a2-b3c4-4d5e-8f6a-7b8c9d0e1f23',
);
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="appId" type="string (uuid)" required>
  ID do app.
</ParamField>

<ParamField path="logId" type="string (uuid)" required>
  ID do log.
</ParamField>

## Resposta

`200 OK`

`request` e `response` são strings (corpo enviado e resposta do provedor); `response`, `statusCode` e `duration` (ms) podem ser `null` se o envio falhou antes da resposta.
