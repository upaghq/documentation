Remove os ScriptTags do checkout na loja e limpa o `scriptTagId` da `config`. O app continua cadastrado; para removê-lo use [Excluir app](./delete). Só apps `shopify`.

Permissão: `app.write` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl -X DELETE https://api.upag.dev/v1/apps/c8d9e0f1-a2b3-4c4d-9e5f-6a7b8c9d0e12/uninstall \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const app = await upag.apps.uninstall('c8d9e0f1-a2b3-4c4d-9e5f-6a7b8c9d0e12');
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="appId" type="string (uuid)" required>
  ID do app Shopify.
</ParamField>
