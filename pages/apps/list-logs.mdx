Cada tentativa de envio a um provedor (Spedy, Utmify, Trackup) gera um log com a requisição e a resposta.

Permissão: `app.read` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.dev/v1/apps/b7c8d9e0-f1a2-4b3c-8d4e-5f6a7b8c9d01/logs \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -d "page=1" \
  -d "limit=15"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

// upag.apps.logs.list(appId, params)
const { data, count } = await upag.apps.logs.list('b7c8d9e0-f1a2-4b3c-8d4e-5f6a7b8c9d01', {
  page: 1,
  limit: 15,
});
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="appId" type="string (uuid)" required>
  ID do app.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Página (mínimo 1).
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Itens por página (mínimo 1).
</ParamField>
