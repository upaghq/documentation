Exclusão lógica. Em apps Shopify, [desinstale o script](./uninstall) antes se quiser removê-lo da loja.

Permissão: `app.write` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl -X DELETE https://api.upag.dev/v1/apps/b7c8d9e0-f1a2-4b3c-8d4e-5f6a7b8c9d01 \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

await upag.apps.delete('b7c8d9e0-f1a2-4b3c-8d4e-5f6a7b8c9d01');
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="appId" type="string (uuid)" required>
  ID do app.
</ParamField>

## Resposta

`204 No Content` — sem corpo em caso de sucesso.

`404` (`APP_NOT_FOUND`) se o app não existir.
