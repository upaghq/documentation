Permissão: `sub_account.read` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.dev/v1/sub-accounts \
  -H "Authorization: Bearer sk_test_your_api_key" \
  -d "limit=20" \
  -d "offset=0"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const { data, count, limit, offset } = await upag.subAccounts.list({ limit: 20, offset: 0 });
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField query="limit" type="integer" default="20">
  Itens por página (1 a 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Deslocamento (≥ 0). Diferente dos demais recursos, esta listagem não usa `page`.
</ParamField>

## Resposta

`200 OK` — além de `data` e `count` (total), devolve `limit` e `offset` aplicados.
