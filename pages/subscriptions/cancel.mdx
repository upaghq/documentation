---
title: 'Cancelar Assinatura'
description: 'Cancela uma assinatura imediatamente'
openapi: 'DELETE /api/v1/subscriptions/{id}'
---

Cancela uma assinatura imediatamente. O acesso ao serviço é encerrado no momento do cancelamento. Para cancelar ao final do período atual, utilize a opção `cancelAtPeriodEnd` na atualização da assinatura.

## Endpoint

<CodeGroup>
```bash cURL
curl -X DELETE https://api.upag.io/v1/subscriptions/sub_abc123xyz \
  -H "Authorization: Bearer {token}"
```

```javascript SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const subscription = await upag.subscriptions.cancel('sub_abc123xyz');
```
</CodeGroup>

## Parâmetros

<ParamField path="id" type="string" required>
  ID único da assinatura, começando com `sub_`.
</ParamField>
