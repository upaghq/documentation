Uma assinatura representa uma cobrança recorrente de um cliente por um produto ou serviço. Faturas são geradas automaticamente a cada período de renovação.

## <Icon icon="folder-tree" type="solid"/> Estrutura

Uma assinatura é representada em nossa API pela seguinte estrutura:

```json
{
  "id": "sub_abc123xyz",
  "livemode": false,
  "customer": "cus_ahwDXrgYvur89iPs",
  "paymentMethod": "pm_abc123xyz",
  "status": "active",
  "currency": "BRL",
  "interval": "month",
  "intervalCount": 1,
  "cancelAtPeriodEnd": false,
  "startDate": 1731622178441,
  "endDate": null,
  "trialStartDate": null,
  "trialEndDate": null,
  "currentPeriodStart": 1731622178441,
  "currentPeriodEnd": 1734214178441,
  "createdAt": 1731622178441,
  "updatedAt": 1731622178441,
  "canceledAt": null,
  "items": [
    {
      "id": "si_abc123xyz",
      "product": "prod_xyz789abc",
      "price": "price_def456ghi",
      "name": "Plano Pro",
      "amount": 9900,
      "quantity": 1,
      "createdAt": 1731622178441,
      "updatedAt": 1731622178441
    }
  ]
}
```

## Atributos:

<AccordionGroup>
  <Accordion title="id:">
    ```json {2}
    {
      "id": "sub_abc123xyz",
    }
    ```

    `id` : <u> string. </u> <br />
    Identificador único da assinatura, começando com `sub_`
  </Accordion>

  <Accordion title="livemode:">
    ```json {2}
    {
      "livemode": false,
    }
    ```
    `livemode` : <u> boolean. </u> <br />
    Indica se a assinatura está em modo de produção (`true`) ou teste (`false`)
  </Accordion>

  <Accordion title="customer:">
    ```json {2}
    {
      "customer": "cus_ahwDXrgYvur89iPs",
    }
    ```
    `customer` : <u> string. </u> <br />
    ID do cliente associado à assinatura. Veja a referência completa <a href="../customers/reference">aqui</a>
  </Accordion>

  <Accordion title="paymentMethod:">
    ```json {2}
    {
      "paymentMethod": "pm_abc123xyz",
    }
    ```
    `paymentMethod` : <u> string | null. </u> <br />
    ID do método de pagamento utilizado para as cobranças recorrentes. Veja a referência completa <a href="../payment-methods/reference">aqui</a>
  </Accordion>

  <Accordion title="status:">
    ```json {2}
    {
      "status": "active",
    }
    ```
    `status` : <u> string. </u> <br />
    Status atual da assinatura

    <Info>
      | Status | Descrição |
      | ----------- | ------------------------------------- |
      | `active` | **A assinatura está ativa e sendo cobrada** |
      | `trialing` | **A assinatura está em período de teste** |
      | `past_due` | **O pagamento está atrasado** |
      | `canceled` | **A assinatura foi cancelada** |
      | `unpaid` | **A assinatura está inadimplente** |
      | `incomplete` | **A assinatura está pendente de confirmação** |
    </Info>
  </Accordion>

  <Accordion title="interval:">
    ```json {2}
    {
      "interval": "month",
    }
    ```
    `interval` : <u> string. </u> <br />
    Intervalo de cobrança: `day`, `week`, `month`, `year`
  </Accordion>

  <Accordion title="intervalCount:">
    ```json {2}
    {
      "intervalCount": 1,
    }
    ```
    `intervalCount` : <u> number. </u> <br />
    Quantidade de intervalos entre cada cobrança. Ex.: `intervalCount: 3` com `interval: month` = cobrança a cada 3 meses
  </Accordion>

  <Accordion title="cancelAtPeriodEnd:">
    ```json {2}
    {
      "cancelAtPeriodEnd": false,
    }
    ```
    `cancelAtPeriodEnd` : <u> boolean. </u> <br />
    Se `true`, a assinatura será cancelada ao final do período atual em vez de renovar
  </Accordion>

  <Accordion title="currentPeriodStart / currentPeriodEnd:">
    ```json {2-3}
    {
      "currentPeriodStart": 1731622178441,
      "currentPeriodEnd": 1734214178441,
    }
    ```
    `currentPeriodStart` / `currentPeriodEnd` : <u> number. </u> <br />
    Timestamps Unix indicando o início e o fim do período de cobrança atual
  </Accordion>

  <Accordion title="trialStartDate / trialEndDate:">
    ```json {2-3}
    {
      "trialStartDate": null,
      "trialEndDate": null,
    }
    ```
    `trialStartDate` / `trialEndDate` : <u> number | null. </u> <br />
    Timestamps Unix do período de teste. `null` se não há período de teste
  </Accordion>

  <Accordion title="items:">
    ```json {2-10}
    {
      "items": [
        {
          "id": "si_abc123xyz",
          "product": "prod_xyz789abc",
          "price": "price_def456ghi",
          "name": "Plano Pro",
          "amount": 9900,
          "quantity": 1
        }
      ]
    }
    ```
    `items` : <u> array. </u> <br />
    Lista de itens da assinatura. Cada item contém `id`, `product`, `price`, `name`, `amount` (em centavos), `quantity`, `createdAt` e `updatedAt`
  </Accordion>

  <Accordion title="canceledAt:">
    ```json {2}
    {
      "canceledAt": null,
    }
    ```
    `canceledAt` : <u> number | null. </u> <br />
    Timestamp Unix indicando quando a assinatura foi cancelada. `null` se ativa
  </Accordion>

  <Accordion title="createdAt:">
    ```json {2}
    {
      "createdAt": 1731622178441,
    }
    ```
    `createdAt` : <u> number. </u> <br />
    Timestamp Unix indicando quando a assinatura foi criada
  </Accordion>

  <Accordion title="updatedAt:">
    ```json {2}
    {
      "updatedAt": 1731622178441,
    }
    ```
    `updatedAt` : <u> number. </u> <br />
    Timestamp Unix indicando quando a assinatura foi atualizada pela última vez
  </Accordion>
</AccordionGroup>
