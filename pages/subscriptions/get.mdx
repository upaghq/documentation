---
title: 'Buscar Assinatura por ID'
description: 'Retorna os detalhes de uma assinatura específica'
openapi: 'GET /api/v1/subscriptions/{id}'
---

Retorna as informações completas de uma assinatura específica pelo seu ID.

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.io/v1/subscriptions/sub_abc123xyz \
  -H "Authorization: Bearer {token}"
```

```javascript SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const subscription = await upag.subscriptions.retrieve('sub_abc123xyz');
```
</CodeGroup>

## Parâmetros

<ParamField path="id" type="string" required>
  ID único da assinatura, começando com `sub_`.
</ParamField>
