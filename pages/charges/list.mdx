Lista as cobranças (Pix, cartão e boleto) da conta, da mais recente para a mais antiga. Filtre por cliente ou status.

Permissão: `charge.read`. Apenas chave secreta (`sk_…`).

<Note>
  Os exemplos usam produção (`https://api.upag.io/v1`) com `sk_live_…`. Para testar, use o sandbox (`https://api.upag.dev/v1`) com `sk_test_…`.
</Note>

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.io/v1/charges \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -d "page=1" \
  -d "limit=15" \
  -d "status=paid" \
  -d "customer=8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83" \
  -d "includes=customer,items"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_live_your_api_key');

const { data, count } = await upag.charges.list({
  page: 1,
  limit: 15,
  status: 'paid',
  customer: '8c1f0a26-5d3b-4f1e-9c72-1a4e6b9d0f83',
  includes: 'customer,items',
});
```
</CodeGroup>

## Parâmetros

<ParamField query="page" type="integer" default="1">
  Página, a partir de 1.
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Itens por página, mínimo 1.
</ParamField>

<ParamField query="customer" type="string (uuid)">
  Só as cobranças deste cliente.
</ParamField>

<ParamField query="status" type="string">
  Só as cobranças neste status: `pending`, `paid`, `expired`, `failed`, `in_review`, `refunded`, `partially_refunded` ou `chargeback`. Valor desconhecido retorna `422`.
</ParamField>

<ParamField query="includes" type="string">
  Relações a embutir, separadas por vírgula: `customer` (objeto cliente no lugar do UUID) e `items` (lista de itens em cada cobrança). `card` é aceito, mas não altera a resposta. Valor desconhecido retorna `422`.
</ParamField>

## Resposta

`200 OK`. `count` é o total de cobranças que atendem aos filtros (não só da página).
