---
title: 'Excluir layout de checkout'

---

Exclusão lógica: o layout deixa de aparecer na listagem.

Permissão: `checkout_layout.write` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl -X DELETE https://api.upag.dev/v1/checkout/layouts/c1d2e3f4-5a6b-4c7d-8e9f-0a1b2c3d4e5f \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

await upag.checkoutLayouts.delete('c1d2e3f4-5a6b-4c7d-8e9f-0a1b2c3d4e5f');
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="layoutId" type="string (uuid)" required>
  ID do layout.
</ParamField>

## Resposta

`204 No Content` — sem corpo em caso de sucesso.

`404` (`CHECKOUT_LAYOUT_NOT_FOUND`) se o layout não existir.
