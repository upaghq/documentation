Um layout define a aparência do checkout (tema, favicon e blocos). Associe um layout a um [link de pagamento](../payment-links/reference) pelo campo `checkoutLayout`.

    "radius": "0.65rem",
    "background": "oklch(0.985 0 0)",
    "foreground": "oklch(0.145 0 0)",

## Atributos

<AccordionGroup>
  <Accordion title="name">
    Nome do layout (1 a 255 caracteres).
  </Accordion>
  <Accordion title="theme">
    Objeto de cores e estilo (valores em string, ex.: `oklch(...)`). Se não for enviado na criação, a API aplica o tema padrão. Chaves obrigatórias quando o tema é enviado: `radius`, `background`, `foreground`, `card`, `card-foreground`, `popover`, `popover-foreground`, `primary`, `primary-foreground`, `secondary`, `secondary-foreground`, `muted`, `muted-foreground`, `accent`, `accent-foreground`, `destructive`, `destructive-foreground`, `success`, `success-foreground`, `warning`, `warning-foreground`, `border`, `input`, `ring`. Opcional: `font`.
  </Accordion>
  <Accordion title="favicon">
    URL ou identificador do favicon (até 255 caracteres), ou `null`.
  </Accordion>
  <Accordion title="desktop / mobile">
    Objetos livres com a configuração de blocos do checkout em cada dispositivo, ou `null`.
  </Accordion>
</AccordionGroup>
