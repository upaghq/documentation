Permissão: `product.read` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl -G https://api.upag.io/v1/products \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -d "page=1" \
  -d "limit=15" \
  -d "includes=prices"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_live_your_api_key');

const { data, count } = await upag.products.list({ page: 1, limit: 15, includes: 'prices' });
```
</CodeGroup>

<Note>
  Os exemplos usam produção (`https://api.upag.io/v1`) com `sk_live_…`. Para testar, use o sandbox (`https://api.upag.dev/v1`) com `sk_test_…`.
</Note>

## Parâmetros

<ParamField query="page" type="integer" default="1">
  Página (mínimo 1).
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Itens por página (mínimo 1).
</ParamField>

<ParamField query="includes" type="string">
  Relações a embutir em cada produto. O único valor aceito é `prices`, que adiciona o array `prices` com os [preços](../prices/reference) do produto, do mais novo para o mais antigo, incluindo os arquivados (`active: false`). Um produto sem preços volta com `prices: []`. Sem `includes`, o campo `prices` não aparece. Um valor desconhecido retorna `422`.
</ParamField>

## Resposta

`200 OK` — `count` é o total de produtos da conta. O exemplo usa `includes=prices`.
