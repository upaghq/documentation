---
title: 'Obter produto'
description: 'Consulta um produto pelo ID'
sidebarTitle: 'Obter'
api: 'GET https://api.upag.io/v1/products/{productId}'
---

Permissão: `product.read` (chave secreta).

## Endpoint

<CodeGroup>
```bash cURL
curl https://api.upag.dev/v1/products/0b9c1f3e-6a4d-4c1e-9d55-3f1f6a7c2e10 \
  -H "Authorization: Bearer sk_test_your_api_key"
```

```javascript Node.js SDK
import { Upag } from 'upag';

const upag = new Upag('sk_test_your_api_key');

const product = await upag.products.retrieve('0b9c1f3e-6a4d-4c1e-9d55-3f1f6a7c2e10');
```
</CodeGroup>

<Note>
  Em produção use `https://api.upag.io/v1` com `sk_live_...`.
</Note>

## Parâmetros

<ParamField path="productId" type="string (uuid)" required>
  ID do produto.
</ParamField>

## Resposta

`200 OK`

```json Response
{
  "id": "0b9c1f3e-6a4d-4c1e-9d55-3f1f6a7c2e10",
  "name": "Plano Pro",
  "description": "Acesso completo à plataforma",
  "image": "https://example.com/plano-pro.png",
  "createdAt": "2026-03-18T11:00:00.000Z",
  "updatedAt": "2026-03-18T11:00:00.000Z"
}
```

`404` (`PRODUCT_NOT_FOUND`) se o produto não existir ou pertencer a outra conta. UUID malformado retorna `422`.
