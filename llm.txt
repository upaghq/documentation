# Upag Documentation

> Dois produtos no mesmo site Mintlify: **Billing** (gateway) e **Core** (conta digital / banking API).

## Hosts

- **Billing API:** `https://api.billing.upag.io/v1`
- **Core API:** `https://api.upag.io/v1` — autenticação `Authorization: Bearer sk_...`

## Billing

- Abas: **Guias**, **Referência**, **Webhooks**, **SDK**, **Simulador**
- Guias: `pages/billing/guides/` (quickstart, checkout-hosted, subscription-recurring)
- Referência: endpoints REST em `pages/billing/{customers,payments,...}/`
- SDK: `pages/billing/sdk/overview.mdx`

## Core

- Abas: **Guias**, **Referência**, **Webhooks** (sem SDK)
- Guias: `pages/core/guides/` (quickstart, pix-charge, pix-transfer)
- Referência: `pages/core/{charges,transfers,customers,sub-accounts}/`

## Navegação

`docs.json` → `navigation.products` (switcher Billing / Core).

## Uso para assistentes

Integração ponta a ponta → aba **Guias**. Campos e contratos HTTP → aba **Referência**. Eventos → aba **Webhooks**.
